BOOGERMANPC

A Pick and Flick Adventure — enhancement port framework

Click to boot (unlocks audio). Your own cartridge dump runs locally — nothing is uploaded.

Arrows = D-padZ/X/C = A/B/CA/S/D = X/Y/Z Enter = StartRShift = ModeH = help

Keyboard

Controller

Gamepad (standard layout): X=A, A=B, B=C, Y=X, LB=Y, RB=Z, Start/Back = Start/Mode. First connected pad maps to port 1.

Add cheat

Codes are decoded and applied by the core itself. Game Genie codes are region-specific — this dump is the EU version.

Save states

F5 = save selected slot, F8 = load selected slot. Click a card to select. States are core snapshots (RAM + hardware), exportable as files.

Enhancement mods

Drop .js / .json / .ips / .bps files anywhere on the page. ROM patches apply at boot; scripts, shaders and cheats apply live. See mods/README.md for the format.
